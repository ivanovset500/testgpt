Справочник «Типы камней»

Справочник вызывается из пункта меню «Справочники» - «Нормативные юв. справочники» - «Типы камней».

Справочник «Типы камней» предназначен для хранения типов драгоценных камней закрепляемых в ювелирных изделиях.

При вводе информации о типе драгоценных камней заполняются следующие реквизиты.

Наименование – указывается наименование типа драгоценного камня.

Сокращение – указывается сокращенное наименование типа драгоценного камня. Реквизит используется для формирования наименования камня в справочнике «Номенклатура» (при незаполненном поле «Сокращение» в формировании наименования камня участвует поле «Наименование»).

На закладке «Основные данные» заполняются следующие реквизиты. Наличие характеристик камня – группа реквизитов, определяющих наличие или отсутствие у данного типа драгоценного камня таких характеристик как цвет, группа цветов, группа дефектов, рассев. Заполнение реквизитов, отмеченных флагом, при описании нового камня данного типа в справочнике «Номенклатура», обязательно (контролируется конфигурацией). Расчет цены за вес – указывается признак расчета цены за вес по умолчанию. Используется для первоначального заполнения аналогичного реквизита «Весовой» справочника «Номенклатура» при создании нового элемента. Учет в каратах – указывается признак учета веса камня в каратах, а не в граммах. Используется для первоначального заполнения аналогичного реквизита «Учет в каратах» справочника «Номенклатура» при создании нового элемента. Для более точного и подробного описания камней и вставок у справочника «Типы камней» существует несколько подчиненных справочников доступных для редактирования на соответствующих закладках. Справочники не выведены в отдельный пункт меню, так как их заполнение имеет смысл, только при описании геммологических характеристик конкретного типа камня.
